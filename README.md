# Хуруу — Монгол бичих дасгал

Монгол кирилл үсгийг арван хуруугаар бичиж сурах веб дасгал. Сервер шаардахгүй,
статик файлууд. Ахиц одоогоор хөтчийн `localStorage` дээр хадгалагдана.

## Файлын бүтэц

| Файл | Үүрэг |
|---|---|
| `index.html` | Хуудасны бүтэц |
| `styles.css` | Бүх загвар (бараан/цайвар горим) |
| `layout.js` | Гарын байрлал: товч ↔ үсэг ↔ хуруу |
| `lessons.js` | Агуулга: сургалтын замнал, үгийн сан, текст үүсгэгч |
| `app.js` | Дасгалын логик, хэмжүүр, ахицын хадгалалт |
| `dist/` | Хостинг дээр тавигдах хуулбар (`.openai/hosting.json`) |

`dist/`-ийг **гараар бүү засаарай** — `npm run build` үүнийг дахин үүсгэнэ.

## Командууд

```
npm run check    # агуулгын шалгалт (бичигдэхгүй тэмдэгт, үсгийн хамрах хүрээ г.м.)
npm run build    # шалгалт + dist/ рүү хуулах
npm run serve    # http://localhost:4321 дээр турших
```

`index.html`-ийг шууд давхар товшиж (file://) нээж болно — ES модуль ашиглаагүй.

## Сургалтын замнал

26 дасгал, 4 үе шат: үндсэн эгнээ → дээд эгнээ → доод эгнээ → том үсэг, тэмдэг,
өгүүлбэр. Үсэг бүр яг нэг дасгалд танилцуулагдаж, нийт 35 үсгийг бүрэн хамарна.

- Дасгалын текст **удаа бүр шинээр** зохиогдоно (195 үгийн сангаас), тул цээжлэх боломжгүй.
- 90%-иас дээш нарийвчлалтай бичвэл дараагийн дасгал онгойно.
- Од: ⭐ тэнцсэн · ⭐⭐ 95% ба хүрэх хурд · ⭐⭐⭐ 98% ба хурдны 125%.
- Багш «Бүх дасгалыг онгойлгох» сонголтоор түгжээг салгаж болно.

## Хэмжүүр

- **Тэмдэгт/мин (CPM)** — үндсэн хэмжүүр. Монгол үг урт тул үг/мин төөрөгдүүлдэг.
- **Нарийвчлал** — *эхний удаад* зөв дарсан тэмдэгтийн эзлэх хувь. Буцаах товчоор
  засаад дээшлүүлэх боломжгүй. Түүхий нарийвчлал (`rawAccuracy`) тусад нь хадгалагдана.

## Уран зохиолын текст

19 бэлэн текст: Д. Нацагдоржийн «Миний нутаг»-аас (нийтийн хүртээл), монгол
ардын зүйр цэцэн үг, сургалтын зориулалтаар бичсэн энгийн текстүүд.

**Текст нэмэх** товчоор өөрийн шүлэг, өгүүллэг, хичээлийн текстээ хуулж
тавина. Word, вэбээс хуулсан текстийн энэ гарын байрлалд байхгүй тэмдэгтийг
автоматаар засна (`«» → "`, `— → -`, `! → .`, `… → ...`, хаалт, латин үсэг
хасагдана) бөгөөд юуг зассан, юуг хассанаа шууд харуулна. Нэмсэн текст
уран зохиол ба хугацаатай сорил хоёрт `✎` тэмдэгтэй гарч ирнэ, нөөц файлд
хамт хадгалагдана. Дээд тал нь 50 текст, тус бүр 5000 тэмдэгт.

Зохиогчийн эрхтэй бүтээл нэмэхдээ зөвшөөрлөө анхаараарай. Бэлэн текстүүд нь
нийтийн хүртээл буюу ардын аман зохиол.

## Үр дүнгийн түүх

Дасгал дуусмагц үр дүн **огноо, цагийн хамт** хөтөч дээр хадгалагдаж, «Дасгалын
түүх» хүснэгтэд харагдана (сүүлийн 200). Хугацаатай сорилыг 30 секундээс
10 минут хүртэл сонгоно.

- **Excel рүү татах** — бүх түүхийг CSV болгож компьютер дээр хадгална
  (UTF-8 BOM ба `sep=;` тул Excel кирилл үсгийг зөв нээнэ).
- **Нөөц хадгалах / Нөөцөөс сэргээх** — бүх ахицыг JSON файлаар. Хөтчийн
  санах ой цэвэрлэгдвэл, эсвэл өөр компьютер руу шилжихэд хэрэгтэй.
- **Түүх цэвэрлэх** — зөвхөн түүхийг устгана, од ба дээд амжилт үлдэнэ.

Нэг хөтөч = нэг хүүхдийн ахиц. Хэд хэдэн хүүхэд нэг компьютер дээр бол
нөөц файлаар тусгаарлах буюу дараагийн шатны класс кодыг хүлээнэ.

## Дараагийн шат: өгөгдлийн сан

Сессийн бичлэг (`saved.history`) нь өгөгдлийн сангийн мөртэй ижил бүтэцтэй:

```js
{ id, at, mode, lessonKey, lessonName, cpm, wpm, accuracy, rawAccuracy,
  chars, attempts, errors, seconds, stars, mistakes, charMs, synced }
```

`id` нь идемпотент түлхүүр (`unique (student_id, client_id)`), `synced` нь офлайн
дараалалд зориулсан туг. Багшийн самбар, класс код, Supabase схемийг дараагийн
шатанд нэмнэ.
